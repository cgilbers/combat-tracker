# Encounter Snapshots and Lifecycle

Party management, creature authoring, encounter preparation, and live combat are separate workspaces. Creature records are reusable library content, while encounters are one-time scenarios that capture a full creature-data snapshot the first time a creature type is added. Further groups of that type in the same encounter reuse that snapshot, so later library edits or deletion cannot change prepared or running combat; encounter-specific stat edits may change only the encounter's copy in a separate workflow. Encounters are created as named Drafts, transition to Active, Paused, and Complete, and retain their live run state in the same record; only one may be Active, switching runs pauses the previous one, and reload restores an Active run as Paused. Creature groups have a creature type and quantity, share initiative, and preserve individual creature HP. Completed encounters remain history; duplicating one creates a fresh Draft with its exact snapshots and composition but no run state.
